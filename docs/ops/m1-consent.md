# M1 真人录音复测：知情同意书

> 对应议题：[zhanglunet/hearsay#4](https://github.com/zhanglunet/hearsay/issues/4)  
> 用途：录音者阅读并签署（或电子确认）后，方可开始采集。  
> 版本：草稿 2026-10-23 · 路径：`docs/ops/m1-consent.md`

---

## 1. 项目与目的

Hearsay 是一个面向英语学习者的开源项目（公开仓库：`https://github.com/zhanglunet/hearsay`）。  
当前处于 **M1 技术风险验证** 阶段。此前实验 A（语法错误在转写中的保留率）与实验 C（词级时间戳 / 切句）使用的是 **合成语音**，无法覆盖真实学习者的停顿、重复、自我修正与吐字含糊。

本次邀请您自愿参与 **真人录音复测**，目的仅限于：

1. 用真人朗读复测实验 A：确认「原样转写」（含 verbatim prompt）在真人语音上是否仍有效；
2. 用真人跟读复测切句：评估「用原文句子首末词匹配 whisperX 词级时间戳」定句边界的误差是否仍满足阈值（句边界误差 &lt; 150 ms 的比例 ≥ 90%）。

**本采集不用于商业广告、不用于对外公开播放您的声音作为示范音，也不用于训练面向公众发布的语音合成模型。**

---

## 2. 您将录什么

预计总时长约 **20–40 分钟**（含说明与重录），内容分两部分：

| 部分 | 内容 | 说明 |
|---|---|---|
| 实验 A 朗读 | `experiments/exp_a_grammar/sentences.json` 中的 **24 句英文** | 句子中 **故意植入了语法错误**（如 *two book*、*She go*）。请 **照稿朗读，不要自行纠正**。 |
| 跟读（shadow） | `experiments/exp_c_timestamps/sentences.txt` 中的 **若干句**（组织方会当场指定，建议约 10–20 句） | 模拟跟读块：按屏幕或纸质稿朗读即可，允许自然停顿；无需背诵。 |

另可能请您口头确认：大致英语水平（自报 **A2 / B1 / B2** 即可）、母语为中文、年龄是否 ≥ 18 岁。这些只用于分档统计，不公开真实姓名。

## 3. 我们如何使用、保存与删除

### 3.1 用途

- 在本地或项目控制的计算环境中，用已有实验脚本（如 `exp_a_grammar/run.py` 及切句评估脚本）做转写、对齐与统计；
- 产出 **去标识的结果表**（例如保留率、句边界误差、配置对比），写入复测报告，用于更新设计建议（对应报告 §2.6、§4.4 一类结论）；
- 报告与结果表中 **不会出现您的真实姓名**；说话人仅以匿名编号标识（如 `S01`）。

### 3.2 默认存储策略（重要）

| 数据类型 | 默认做法 |
|---|---|
| **音频文件（wav 等）** | **默认不提交、不上传到公开 GitHub 仓库**。仅保存在组织方约定的本地或私有位置，供本次复测分析使用。 |
| **结果 CSV / 汇总 JSON / 报告中的数字与匿名对比表** | 可以写入公开仓库（不含可识别身份信息、不含原始音频）。 |
| **签署的同意记录** | 由组织方单独保存（纸质或加密电子档），**不**放入公开仓库。 |

若将来确有必要把 **某条或全部音频** 放入仓库或对外共享，必须 **另行征得您的明确书面同意**，并说明范围与期限；您有权拒绝，且拒绝不影响您已完成的其他贡献。

### 3.3 保存期限与删除

- 音频默认保存至：**本次 M1 复测报告合并完成之日后 90 天**，或您书面要求删除之日（以较早者为准），期满后由组织方删除本地音频副本。
- 已写入公开仓库的 **去标识结果表与报告文字** 属于实验记录，一般随仓库保留；其中不含您的姓名与原始音频。
- 您可随时要求删除仍由组织方持有的 **可识别到您的音频与同意记录**（见第 4 节）。

### 3.4 可能接触数据的人

仅限直接负责本次复测的组织方成员与受其委托、且需知悉的技术协作者（例如协助跑脚本、做 Praat 句边界标注的人）。不会向无关第三方出售您的录音。

---

## 4. 自愿参与与撤回

- 参与完全自愿；不参与或中途退出 **不会** 带来任何不利后果。
- 录音过程中您可随时要求暂停、重录某一句，或终止整场采集。
- **撤回同意**：采集结束后，您仍可联系下方联系人，要求删除组织方持有的您的音频及可关联到您的同意记录。  
  - 若结果 CSV 已合入公开仓库且其中仅含匿名编号与统计数字，则 **无法从已发布的公开提交中「收回」这些数字**；但组织方会停止继续使用您的音频，并删除本地音频副本。  
  - 若音频从未入库（默认情况），撤回后组织方删除本地音频即可。

---

## 5. 风险与不适

- 主要负担是占用一段时间朗读英文；内容为日常句与含语法错误的朗读句，无羞辱性或敏感私密话题。
- 若您对「故意读错」感到不适，可随时跳过该句或终止采集。
- 请在安静、您感到舒适的环境中录制；不要在可能泄露他人隐私的场合录音。

## 6. 年龄与资格

- 本次复测仅面向 **年满 18 周岁** 的参与者。
- 母语为中文（普通话或常用汉语方言均可），英语水平自报约在 **A2–B2**。
- 若您未满 18 岁，请勿参与本采集。
