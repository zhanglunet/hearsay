# Hearsay 统一首页与一键启动

把各切片收进一个入口：今日计划、到期复习卡、can-do 进度摘要和全部练习链接。

## 一键启动

```bash
cd prototype
python start_all.py
```

统一首页在 **http://127.0.0.1:8764/**，其余服务同时启动：

| 入口 | 端口 |
|---|---|
| 统一首页 | 8764 |
| M1 跟读 | 8765 |
| M2 对话 / 复习 | 8766 |
| M4 计划与 can-do 进度 | 8767 |
| 复述 | 8768 |
| 听力理解题 | 8769 |

各服务独立线程，Ctrl-C 全部停止。LLM（`HEARSAY_LLM*`）、存储
（`HEARSAY_M3_STORE`）、批处理（`HEARSAY_M2_BATCH`）等仍用原有环境变量，
不需要额外配置。只用标准库，不下载模型。

首页只读 M3 学习者存储并展示计划；完整评分和证据编辑在 M4 进度页完成。

也可以只启动首页：`python -m home`（`HEARSAY_HOME_PORT` 改端口）。
