# Hearsay 统一首页与一键启动

把各切片收进一个入口：今日计划、到期复习卡、can-do 进度摘要和全部练习链接。

## 一键启动

```bash
cd prototype
python start_all.py
```

统一首页在 **http://127.0.0.1:8764/**。对外只有这一个端口，各切片挂在路径前缀下：

| 入口 | 路径 |
|---|---|
| 统一首页 | `/` |
| 听力理解题 | `/listen/` |
| M1 跟读 | `/shadow/` |
| 复述 | `/retell/` |
| M2 对话 / 复习 | `/converse/` |
| M4 计划与 can-do 进度 | `/plan/` |

首页兼做网关：切片本身只监听 `127.0.0.1` 的临时端口，首页把 `/<kind>/...` 反向代理过去
（`/<kind>` 会 301 到带斜杠的地址）。所以容器里 `HEARSAY_HOST=0.0.0.0` 只影响首页，
上公网只需要开放 `HEARSAY_HOME_PORT` 一个端口。各切片前端都用相对路径，单独启动
（例如 `python -m m1_shadow`，仍在 8765）时照样能用。

各服务独立线程，Ctrl-C 全部停止。LLM（`HEARSAY_LLM*`）、存储
（`HEARSAY_M3_STORE`）、批处理（`HEARSAY_M2_BATCH`）等仍用原有环境变量，
不需要额外配置。只用标准库，不下载模型。

首页只读 M3 学习者存储并展示计划；完整评分和证据编辑在 M4 进度页完成。

也可以只启动首页：`python -m home`（`HEARSAY_HOME_PORT` 改端口）。这时没有网关，入口链接退回各切片的本地端口（8765–8769），需要另行启动对应切片。
